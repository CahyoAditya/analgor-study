# Panduan Responsi Analisis Algoritme

Materi ini ditujukan kepada peserta responsi. Bab 1–7 memuat pembahasan; Bab 4–7 disusun menurut urutan nomor pada lembar responsi. Setiap bab juga memiliki latihan terpisah. Jika sebuah soal tidak menentukan rincian penting, pembahasan menyebut asumsi yang dipakai.

| Responsi | Materi | Penjelasan singkat |
| --- | --- | --- |
| 1 | [Dasar matematika](bab-01-dasar-matematika.md) | Titik potong fungsi, memilih kelompok, *tree*, gabungan himpunan, dan pembuktian. |
| 2 | [Pertumbuhan fungsi](bab-02-pertumbuhan-fungsi.md) | Suku dominan, perbandingan waktu, frekuensi loop, dan biaya tiap baris program. |
| 3 | [Kasus analisis](bab-03-kasus-analisis.md) | Bukti Big-O, perkiraan waktu, perbandingan algoritme, serta tabel biaya dan frekuensi program. |
| 4 | [Algoritme iteratif](bab-04-algoritme-iteratif.md) | Pembahasan 20 soal responsi: frekuensi, biaya, dan loop yang tidak berhenti; [latihan](latihan-bab-04.md). |
| 5 | [Algoritme rekursif](bab-05-algoritme-rekursif.md) | Pohon rekursi A1–A4, Master B1–B4, TriMergeSort dan QuadHistogram C1–C2; [latihan](latihan-bab-05.md). |
| 6 | [Pencarian](bab-06-pencarian.md) | Pemangkatan modulo A1–A3, matriks monoton B, dan submatriks maksimum C; [latihan](latihan-bab-06.md). |
| 7 | [Pengurutan](bab-07-pengurutan.md) | Insertion, merge, partisi quick sort A, serta transaksi dan Top-K B; [latihan](latihan-bab-07.md). |
